I'm **EvoRuleLab**, founder of the **EvoRule** open-source project — a deterministic-first rule governance engine built in Rust.

In safety-critical and regulated environments, *"I think it's fine"* is not enough — you need *"I can prove it's fine"*. EvoRule makes every decision **provable, replayable and tamper-evident** via a BLAKE3-signed hash chain.

- 🦀 Rust · deterministic execution · audit chains · rule engines
- 🏗️ Building the EvoRule ecosystem: core engine, server, console, agent
- 📍 Changsha, China
